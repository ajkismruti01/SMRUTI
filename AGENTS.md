# SMRUTI Development Guide

## Project Context
SMRUTI is a family memory archive and heritage preservation web application built with React, Vite, and Tailwind CSS.

## Key Folders
- `smruti-frontend/`: React + Vite frontend application.
- `smruti-backend/`: Express + MongoDB backend REST API server.

## Local Development
- `npm run dev`: starts the frontend (Vite) from root or `cd smruti-frontend && npm run dev`.
- `npm run dev:server`: starts the backend server from root or `cd smruti-backend && npm run dev`.
- `npm run build:frontend`: builds the frontend production bundle.
