# SMRUTI - Family Heritage & Memory Archive

A modern, responsive web application for preserving family memories, recording stories, saving traditional recipes, and celebrating family heritage across generations.

## Features

- **Memories**: Browse, filter, and preserve photos, videos, and documents with tagging and locations.
- **Family Stories**: Audio narration and written tales passed down through generations.
- **Family Recipes**: Cherished traditional recipes with ingredients, steps, and storyteller audio.
- **Interactive Family Tree**: Visual generational tree with zoom, pan, and member profile details.
- **Timeline & Milestones**: Milestone journey across decades and years.
- **On This Day**: Relive moments that happened on today's date in history.
- **Global Search**: Search across memories, stories, recipes, people, and events.

## Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS + Radix UI primitives
- **Icons**: Lucide React
- **Routing**: React Router DOM v6
- **Data & State**: React Query + React Context

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
